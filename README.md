# ScreenVeil

Полноэкранная визуальная блокировка для Windows. Программы, загрузки, музыка и другие процессы продолжают работать в фоне. ScreenVeil создаёт отдельную защищённую от системного захвата заставку на каждом мониторе и корректно учитывает масштаб Windows.

Проект входит в карту разработок [Keverq Lab](https://github.com/gevorg1arkasha123-ux/keverq-lab), где ведутся статусы и межпроектные заметки. Исходный код ScreenVeil хранится только в этом репозитории.

## Первый запуск

1. Запустите `setup-password.bat` и дважды введите свой пароль.
2. Запустите `start.bat` — появится размытая заставка.
3. Для выхода введите пароль и нажмите Enter или кнопку «Разблокировать».

## Автоматическая блокировка

Запустите `enable-auto-lock.bat`. Фоновый наблюдатель сразу запустится и будет автоматически открывать ScreenVeil после 15 минут без клавиатуры и мыши. При следующих входах в Windows он запускается автоматически через папку «Автозагрузка».

Чтобы отключить эту функцию, запустите `disable-auto-lock.bat`. Сам ручной запуск `start.bat` продолжит работать.

Пароль не хранится открытым текстом: рядом создаётся `config.json` с солью и PBKDF2-SHA256-хэшем. Чтобы сменить пароль, снова запустите `setup-password.bat`.

## Ограничения

Это визуальная шторка, а не защищённый рабочий стол Windows. Она закрывает обычные окна и блокирует Alt+F4/Alt+Tab внутри приложения, но пользователь с доступом к Ctrl+Alt+Delete, Диспетчеру задач или правами администратора сможет её завершить. Для реальной защиты учётной записи используйте Win+L.

Защита от скриншотов использует Windows API `WDA_MONITOR`: обычные системные средства захвата должны видеть пустую область вместо заставки. Microsoft предупреждает, что это не DRM и не защищает от фотографии экрана, специальных драйверов захвата или административного вмешательства.
